Complete reference guide for the Hiranya Signal Monitor 1.9 (v1.19) 5-Confluence Strategy

Official Specification

1. Core Architecture & Philosophy

The system's core premise is that high-probability 1-minute SPY trades occur only when momentum, cross-market tech flow, broad market breadth, intermediate trend, and local trend all point in the exact same direction.

🟢 5/5 Bullish Alignment
→ BUY / READY (Green)

🔴 5/5 Bearish Alignment
→ SELL / READY (Red)
All 5 independent market factors are trending DOWN simultaneously.
🟡 < 5/5 Alignment

2. The 5 Confluence Factors

Every tick and at every 1-minute candle close, the script evaluates 5 independent binary factors:

# Factor Logic / Formula Bullish Condition (UP) Bearish Condition (DOWN)
1 AK MACD BB Fast EMA (12), Slow EMA (26), Signal (9). Histogram H = MACD - Signal. Bollinger Bands on histogram (Length: 20, Mult: 2.0). (H > 0 and H > H[1]) or H ≥ (basis + 2σ)
(Rising or BB upper breakout)		 H ≤ 0 or H ≤ H[1]
(Histogram declining / below BB)
2 QQQ 1m Trend Cross-asset tech correlation via request.security("QQQ", "1", close) Current QQQ close > Previous QQQ close
(qqqValue > qqqValuePrev)		 Current QQQ close ≤ Previous QQQ close
3 ADD 1m Breadth NYSE Advance-Decline breadth via request.security("USI:ADD", "1", close) Current $ADD > Previous $ADD
(addValue > addValuePrev)		 Current $ADD ≤ Previous $ADD
4 SPY 5m Supertrend Higher-timeframe trend filter via request.security("SPY", "5", Supertrend(ATR=10, Factor=3.0)) 5-min Supertrend is green / uptrend
(dir < 0)		 5-min Supertrend is red / downtrend
(dir > 0)
5 SPY 1m Supertrend Local execution trend directly on chart via ta.supertrend(Factor=3.0, ATR=10) 1-min Supertrend is green / uptrend
(stUp = true)		 1-min Supertrend is red / downtrend
(stUp = false)

3. Signal Triggering & Filtering Mechanics

Alignment Calculations
bullCount = ∑(factors UP)
bearCount = 5 - bullCount
conf = max(bullCount, bearCount)
isBullish = bullCount > bearCount
• BUY Trigger: bullCount == 5 (all 5 factors UP)
• SELL Trigger: bearCount == 5 (all 5 factors DOWN)
• Clean Signal Logic: Fires only on first transition (buySignal and not buySignal[1]) to avoid duplicate alert spamming.
TradingView Visual Output
• BUY Shapes: Green triangle up (BUY) plotted below the trigger candle.
• SELL Shapes: Red triangle down (SELL) plotted above the trigger candle.
• Candle Tinting: When a signal is active, candles are tinted lime green (#00e676) or red (#f44336).
